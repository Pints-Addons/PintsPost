Pint's Postal - Changelog

v1.1.5
- To: box: Backspace no longer fills the name back in, so a wrong first letter can be deleted.
- WoW Forever: fixed an error when opening the Send Mail tab (the money-in-subject helper).

v1.1.4
- Trades and charter requests at the mailbox are no longer turned away by default (tick "Block trades while at the
  mailbox" in the settings to turn it back on).

v1.1.3
- WoW Forever: money shows with the gold, silver and copper icons (the game's own coin text showed bare digits).

v1.1.2
- Contacts: long Guild and Friends lists go a page at a time - scroll with the mouse wheel, or use next / previous.

v1.1.1
- WoW Forever: the contacts book (alts, recently mailed, friends, guild) uses full names, so the To: box gets the right
  person; each alt saves itself again in full at its next login.
- WoW Forever: the inbox buttons (Open All / Open / Return) sit between Prev and Next again, the settings gear is
  beside the close button, and each part of the mailbox sets itself up separately, so one problem can't hide the rest.
- The contacts list closes with the mailbox.

v1.1
- Works on WoW Forever (the modern game client). Classic Era is unchanged.
- Uses the modern item functions where the old ones are gone.

v1.0
- First public release.
- Contacts book by the To: box (your alts, recently mailed, friends, guild) and name autocomplete.
- Open All by mail type (each kind of auction mail, or other mail with money or items); never opens COD mail.
- Tick boxes on the inbox with Open and Return buttons; Shift-click for a range, Ctrl-click for one sender.
- Shift-click a mail to take everything, Ctrl-click to return it, Alt-click a bag item to attach it.
- Expiry icon on each mail - will it come back or be deleted? Click it to do that now.
- Copy a mail's text, Forward a mail and its items.
- Quick-attach buttons for cloth, leather, herbs, ore and bars, enchanting and elemental materials.
- Subject fills in with the gold amount, trades blocked at the mailbox, gold taken reported on close.
